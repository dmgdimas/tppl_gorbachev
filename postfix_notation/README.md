# Стековая машина для постфиксной нотации

Программа вычисляет арифметическое выражение, записанное в постфиксной нотации.

## Возможности

- Поддерживаются операции: `+`, `-`, `*`, `/`
- Поддерживается специальный оператор: `~`
- Программа печатает состояние стека после каждого шага вычисления
- Программа выводит дружелюбные сообщения об ошибках
- Результат выводится в формате:

```text
выражение = результат
```

## Семантика операций

Обычные операции работают как в стековом калькуляторе:

- `a b +` -> `a + b`
- `a b -` -> `a - b`
- `a b *` -> `a * b`
- `a b /` -> `a / b`

Специальный оператор `~`:

1. Если оба операнда не равны `0`:

   ```text
   x y ~ = |x - y|
   ```

2. Если хотя бы один операнд равен `0`:

   - берётся сумма всех значений стека, включая два извлечённых операнда;
   - сумма возводится в квадрат;
   - стек заменяется одним полученным значением.

Такое поведение позволяет примерам из задания корректно завершаться с одним результатом в стеке.

## Как запустить

Перейдите в директорию с решением:

```bash
cd postfix_notation
```

Запустите программу, передав выражение аргументами командной строки.

Лучше передавать выражение в кавычках, особенно из-за символа `~`, который в некоторых оболочках может раскрываться как домашняя директория:

```bash
python main.py "3 0 4 ~ 2 ~"
```

Можно также передавать токены отдельно:

```bash
python main.py 3 0 4 '~' 2 '~'
```

Примеры:

```bash
python main.py "3 0 4 ~ 2 ~"
```

```bash
python main.py "2 2 + 4 - 4 ~ 2 3 * +"
```

Пример вывода для выражения `3 0 4 ~ 2 ~`:

```text
Шаг 1: токен '3' -> стек: [3]
Шаг 2: токен '0' -> стек: [3, 0]
Шаг 3: токен '4' -> стек: [3, 0, 4]
Шаг 4: токен '~' -> стек: [49]
Шаг 5: токен '2' -> стек: [49, 2]
Шаг 6: токен '~' -> стек: [47]
3 0 4 ~ 2 ~ = 47
```

## Обрабатываемые ошибки

Программа завершается с кодом `1` и сообщением в `stderr`, если:

- выражение пустое;
- передан неизвестный токен;
- недостаточно операндов для операции;
- происходит деление на ноль;
- после вычисления в стеке осталось больше одного значения;
- результат не является конечным числом;
- результат слишком большой для представления.

## Тесты

Тесты написаны на `pytest`.

Установите зависимости:

```bash
pip install -r requirements-dev.txt
```

Запустите тесты:

```bash
pytest
```

Запуск с покрытием:

```bash
pytest --cov=main --cov-report=term-missing
```

Или через `coverage`:

```bash
coverage run -m pytest
coverage report -m
```
