# Выбор парадигмы и языка программирования

## Задача 1. Обработка больших данных в реальном времени

**Парадигма:** Императивная, параллельные вычисления (Data Parallelism)

**Язык программирования:** Rust

**Обоснование:**
* Поток данных ~3.3 ГБ/с требует нулевых накладных расходов и отсутствия пауз сборщика мусора.
* Работа 24/7 требует гарантий безопасности памяти и отсутствия утечек - Rust обеспечивает это на уровне компилятора.
* Параллельная парадигма позволяет распределить математические операции по всем ядрам CPU/GPU.

## Задача 2. Прототип ML-сервиса для прогноза погодных условий

**Парадигма:** Функциональная, конвейерная обработка данных

**Язык программирования:** Python

**Обоснование:**
* Дедлайн MVP - 2 недели; Python обеспечивает максимальную скорость разработки и итераций.
* Наличие готовых ML-библиотек (scikit-learn, PyTorch, pandas) закрывает все требования.
* Тяжелые вычисления выполняются на C/C++ под капотом библиотек, поэтому производительность прогноза не страдает.

## Задача 3. Интерактивный UI для торгового терминала

**Парадигма:** Функционально-реактивная (FRP), декларативный UI

**Язык программирования:** TypeScript

**Обоснование:**
* Веб-интерфейс требует экосистемы JavaScript; TypeScript добавляет статическую типизацию для тестируемости.
* Реактивная парадигма (RxJS, React/Vue) корректно обрабатывает множество потоков (WebSocket, REST, события) и зависимости между 50+ виджетами.
* Декларативный рендеринг обеспечивает обновление только измененных частей DOM, укладываясь в лимит 16 мс.

## Задача 4. Прошивка для устройства регистрации температуры

**Парадигма:** Процедурная, событийно-ориентированная (конечные автоматы)

**Язык программирования:** C

**Обоснование:**
* Ограниченные ресурсы (32 КБ RAM) и требование минимального энергопотребления исключают языки с рантаймом и GC.
* Прямой доступ к регистрам GPIO/ADC/UART реализуется через указатели и битовые операции.
* Процедурная парадигма с FSM гарантирует детерминированное время отклика (real-time).
* Компиляторы C существуют для всех архитектур МК (ARM, AVR, RISC-V), что обеспечивает переносимость.
